# Local Fonts

The WOFF2 files in this directory are the Latin subsets used by the application:

- Inter 400-900 variable
- Cinzel 600-900 variable
- Rajdhani 500, 600, and 700

They were downloaded from the official Google Fonts CDN on 2026-07-10 and are
licensed under the SIL Open Font License, Version 1.1. Their local copies keep
production builds independent of the Google Fonts network endpoint.
